\section{Architectural Details and Complexity}
\label{sec:supp_arch}

\paragraph{Pre-fill FLOPs, two-phase inference, and KV-cache scaling.}
Let a frozen LLM have $L$ layers, hidden width $d$, intermediate FFN width
$d_{\mathrm{ff}}$, query/KV projections of widths $(d, 2d_{\mathrm{kv}})$, $N$
visual patches merged into $N_c$ cells, and $T$ text tokens. Full token
concatenation (\emph{LLaVA-Proj}) appends all $N_c$ visual cells across all
$L$ layers, incurring $O\bigl(L(T{+}N_c)^2 d\bigr)$ self-attention compute and
$O(L N_c d_{\mathrm{kv}})$ visual KV-cache overhead during autoregressive
decoding. By contrast, \modelname-Free runs visual encoding in the first
$K{\ll}L$ shallow layers---costing $O(K N^2 d)$ once per image---and keeps all
$L$ causal text layers at sequence length $T$, yielding $O(K N^2 d + L T^2 d)$
attention with zero visual KV entries in language self-attention. Meanwhile,
SAVM computes conditioned rotations once per image--question prefill and reuses
them across every decoding step while querying visual cells in a narrow
$d_q{=}256$ subspace. Tab.~\ref{tab:supp_eff} reports the exact per-patch
FLOPs and exclusive-GPU latency measurements underlying
Fig.~\ref{fig:exp_highlights}(a,b).

\paragraph{Direct vs.\ anchor-pooled spatial retrieval.}
In the $21$k/$28$k reference setup (\texttt{hyb}), SAVM compresses $N_c$ visual
cells into $M{=}16$ learnable anchor tokens $H_\ell^a\in\mathbb{R}^{M\times d_q}$
($d_q{=}256$) before text cross-attention, minimizing memory traffic for broad
perception and anti-hallucination. In the $44$k audited setup
(\texttt{direct\_hyb}), SAVM omits the $M$-anchor bottleneck and applies
post-normalized multi-head cross-attention directly over all $N_c$ positional
cells in the narrow $d_q{=}256$ subspace, eliminating anchor-pooling loss on
fine-grained chart and reasoning queries while still keeping deeper
self-attention at length $T$. In the full $44$k \texttt{qcond}+\texttt{direct\_hyb}
configuration at $N{=}4{,}096$ patches ($N_c{=}1{,}024$, $T{=}64$), restricting
Cayley rotations to the five residual-stream entry projections
(\texttt{rot\_bound}\,{=}\,$0.12$) lowers prefill latency from $108.9$\,ms
($14.4\%$ faster than matched LLaVA-Proj at $127.2$\,ms, $2.67$ vs.\
$9.70$ TFLOPs) to $101.9$\,ms ($19.9\%$ faster, $2.67$ TFLOPs, $-72.5\%$).

\paragraph{Bit-exact text-only decoupling.}
For any text-only input ($I{=}\emptyset$), the rotation context and retrieval
residual are bypassed (\texttt{rotation\_context} inactive), so every layer
executes the exact unmodified linear weights $W_{\ell,p}$ of $f_\theta$ with
$\max|\Delta\text{logits}|=0.0$ and zero extra KV-cache storage or decoding overhead.

\section{Training Mixtures and Hyperparameters}
\label{sec:supp_data}

\paragraph{Dataset auditing and splits.}
The \emph{base} ($21$k) mixture contains $21{,}000$ training and $2{,}408$
validation short-answer visual reasoning items (${\sim}70\%$ multiple choice,
$30\%$ numeric/short text). The \emph{+open} ($28$k) mixture adds $8{,}334$
open-ended items ($6{,}500$ DocVQA/ChartQA and $1{,}834$ GQA items, as cited in
Sec.~\ref{sec:setup}) and $2{,}101$ plane-geometry problems ($28{,}000$
train / $3{,}388$ val). The \emph{debiased} ($44$k) mixture filters out every
image matching any of the $7{,}552$ evaluation images across all six public
benchmarks by exact SHA1 or perceptual $64$-bit dHash (Hamming distance
${\le}2$), enforces strictly image-disjoint train/validation partitions
($39{,}949$ train / $4{,}441$ val rows, zero shared images), and balances
multiple-choice letters A/B/C/D to $1{:}1{:}1{:}1$ and Yes/No items to an exact $1{:}1$ ratio.
